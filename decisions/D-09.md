## Decision

## Options

| Option | What | Cost |
|---|---|---|
| A | A custom-distribution app per pilot store, plus the exemption request | $0 |
| B | Pull requests on a GitHub-connected theme | $0 |
| C | A patched theme file the merchant uploads | $0 |

## Agents' pick

A for pilots, C as fallback, B for agencies

## Risk

App Store apps need a Shopify exemption to edit theme files (write_themes plus an exemption). Shopify replies to exemption requests within about two weeks.

## What this means for agents

- Spike A in M3 confirms whether custom-distribution apps need the exemption, and files the request if needed.
- Alt-text fixes go through the Admin API and need no theme edit.
- Every route must support preview and one-click revert.
