## Decision

B now: the private repo harsh-2711/wideaisle-ledger holds event logs and transcripts. Until the owner creates it, hooks write to a gitignored .agents/ledger/ folder. Move to C once the PoC server exists.

The owner approved B on 2026-10-07, during kickoff.

## Options

| Option | What | Cost |
|---|---|---|
| A | Everything in the main repo (simplest, bloats it) | $0 |
| B | Checkpoints in the main repo; event logs and transcripts in a separate private ledger repo | $0 |
| C | Event logs in Postgres, transcripts in object storage | Cents a month (est.) |

## Agents' pick

B now; C once the PoC server exists

## Risk

Logs written before the ledger repo exists stay on the machine that wrote them.

## What this means for agents

- Hooks append to $WA_LEDGER_DIR/<task>/events.jsonl. It defaults to .agents/ledger/.
- Once the ledger repo exists, point WA_LEDGER_DIR at a clone of it.
- Checkpoints (board.json, TASK.md, HANDOFF.md) stay in the main repo.
