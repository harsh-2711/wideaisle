## Decision

A: a GitHub Project with columns Queued, Running, Blocked on you, In review and Done. The owner creates it; a script mirrors .agents/board.json to it.

The owner approved A on 2026-10-07, during kickoff.

## Options

| Option | What | Cost |
|---|---|---|
| A | GitHub Projects, built into GitHub | $0 |
| B | Linear | Not estimated in the plan |
| C | A small custom dashboard page on our server | Not estimated in the plan |

## Agents' pick

A; it also works on your phone

## Risk

Low. The board lives on GitHub, which the repo already uses.

## What this means for agents

- Hooks update .agents/board.json on every step.
- The sync script pushes board.json to the GitHub Project once the owner creates it and adds a token with project scope.
