## Decision

A: one small server for app, Postgres, queue and scanner. Cloudflare Browser Run for census bursts.

## Options

| Option | What | Cost |
|---|---|---|
| A | One small server for app, database, queue and scanner | About $5 to $15 (est.) |
| B | Managed app host plus managed Postgres | About $20 to $50 (est.) |
| C | Cloudflare Workers plus Browser Run | $5 plan, then $0.09 per browser-hour after 10 hours |

## Agents' pick

A, with Browser Run for census bursts

## Risk

One server is a single point of failure. Fine for up to 20 PoC stores; move Postgres to a managed service at launch.

## What this means for agents

- Spike D in M3 times and costs 1,000 page scans on a small server versus Browser Run.
- Workers Paid is a paid sign-up: send the owner a memo first (D-04).
